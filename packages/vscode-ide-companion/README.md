# Papert Code Companion

The Papert Code Companion extension seamlessly integrates [Papert Code](https://github.com/azharlabs/papert-code). This extension is compatible with both VS Code and VS Code forks.

## Features

- **Open Editor File Context**: Papert Code gains awareness of the files you have open in your editor, providing it with a richer understanding of your project's structure and content.
- **Selection Context**: Papert Code can easily access your cursor's position and selected text within the editor, giving it valuable context directly from your current work.
- **Native Diffing**: Seamlessly view, modify, and accept code changes suggested by Papert Code directly within the editor.
- **Launch Papert Code**: Quickly start a new Papert Code session from the Command Palette (Cmd+Shift+P or Ctrl+Shift+P) by running the "Papert Code: Run" command.
- **Terminal Integration**: Papert Code (installed separately) running within the VS Code integrated terminal can communicate with the extension to access editor context.ly) running within the VS Code integrated terminal
